# Minecraft — спуск вглубь мира

Одностраничный фан-лендинг Minecraft (практика №10). Прокрутка страницы — спуск через слои мира: поверхность → земля → камень → пещеры → глубинный сланец → бедрок → Энд.

- Чистые HTML/CSS/JS, без сборки
- Шрифты: Tiny5 и Golos Text (Google Fonts)
- Изображения собраны из оригинальных текстур Minecraft

Неофициальный фансайт, сделан в учебных целях. Minecraft, текстуры и персонажи принадлежат Mojang Studios.
